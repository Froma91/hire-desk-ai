# PROJECT_HIRE_DESK_AI — Product Context

PROJECT_HIRE_DESK_AI is an intelligent web application that helps job seekers
organize, analyze, and track their job applications.

The application allows the user to paste a job description, extract its
important information, validate the result, save the application, track its
status in a Kanban board, and receive a recommended next action.

## Main user flow

Paste a job description
→ analyze the content
→ validate extracted information
→ save the job application
→ track its status
→ recommend the next action

## Main objective

PROJECT_HIRE_DESK_AI transforms a fragmented job-search process into a clear,
structured, measurable, and action-oriented workflow.

## Target users

- Job seekers
- Students and recent graduates
- People changing careers
- Candidates managing several applications
- People currently using spreadsheets or notes to track applications

## Hackathon constraints

- The project must be completed in six days.
- The MVP must be stable and demonstrable in less than four minutes.
- Prioritize working features over architectural complexity.
- Do not integrate directly with LinkedIn, Indeed, Glassdoor, or JobTeaser.
- Do not scrape employment platforms.
- Do not build a complete CV generator.
- Do not build a complex document management system.
- Do not implement market trend analysis.
- Human validation is required before saving AI-generated information.

## MVP features

- Create, read, update, and delete job applications.
- Paste and analyze a job description.
- Extract structured job information.
- Validate extracted information before saving.
- Display applications in a Kanban board.
- Display basic dashboard statistics.
- Recommend the next best action.
- Use a single demo user for the hackathon MVP.
